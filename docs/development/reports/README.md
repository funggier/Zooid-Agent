- [Development plan review](development-plan-review.md): การตรวจเอกสารตั้งต้น; ไม่มี software qualification

รายงาน implementation ในอนาคตใช้ [report template](../templates/report.md) และต้องมี tested SHA, environment, observed result และข้อจำกัด
